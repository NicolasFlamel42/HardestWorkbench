# Hardest Workbench
The hardest of all workbenches!

This Minecraft Mod aims to make the early-game progression a little more challenging by adding the *Crude Workbench*,
a step on the way to making your first Crafting Table. It imposes unique restrictions that you have to work around.
You will need to procedually upgrade it to unlock the *luxuries* of a 3x3 crafting grid.
